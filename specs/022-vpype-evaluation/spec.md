# Spec 022 — vpype evaluation

**Type:** evaluation slice (no production migration)

**Goal:** Objectively assess whether [vpype](https://vpype.readthedocs.io/) should replace or complement PlotPilot’s SVG geometry pipeline.

**Deliverables:** `research.md`, `comparison.md`, `benchmarks.md`, `recommendation.md`, spike under `experiments/vpype/`, tests in `tests/test_vpype_evaluation.py`.

**Non-goals:** Wire vpype into MainWindow, PlotterService, or change plotter output behavior.
